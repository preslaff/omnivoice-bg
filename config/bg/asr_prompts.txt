# Prompt bank for the ASR playground (omnivoice/cli/asr_playground.py, "read" mode).
#
# WHAT THIS IS FOR. A volunteer is shown one of these lines and reads it aloud. The line
# itself becomes the reference transcript, so read mode costs the volunteer no typing and
# is anchoring-free by construction: the reference existed before the model ever ran.
#
# SELECTION PRINCIPLE. Weighted toward what actually breaks Bulgarian ASR rather than toward
# "typical" prose — numbers in every gender and case, dates, times, money, percentages,
# proper names and place names, addresses, acronyms and abbreviations, foreign borrowings,
# and the homograph pairs the stress front-end cares about. Plain conversational sentences
# are included too, as a control.
#
# LEAKAGE GUARD. Every line here is checked against data/lm/lm_text_gp.txt (the 14.4M-word
# text of the GP-v2 training corpus) on an exact normalized match, so read mode measures
# recognition rather than memorization. Re-run the check after editing:
#     ./venv/bin/python check_prompt_leakage.py
#
# LENGTH. Keep every line comfortably under 15 seconds when read aloud (~25 words max);
# the recorder hard-stops at 15 s.
#
# FORMAT: one sentence per line. Blank lines and #-comments ignored. Order is irrelevant —
# the server spreads coverage per speaker.
